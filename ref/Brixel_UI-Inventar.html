Brixel · Spiel-Client · Stand 06.10.2026

UI-Inventar

Alle Fenster, HUD-Teile, Menüs und Unterdialoge des Spiels, mit Reitern, Knöpfen und den Wegen dorthin. Beschriftungen stehen so, wie sie im Code stehen. Grundlage für das neue Design und das Neu-Verdrahten der Oberflächen.

Modi P Plaza · B Bauplatz · M Match · A Asset-Karte Ord Zeichenreihenfolge der Canvas (höher liegt oben) Modal Kennung in UiState (nimmt Maus und Steuerung)

Einstieg & System

Grundregeln für alle Fenster: Ein offenes Fenster schließt sich mit Esc selbst; ohne offenes Fenster öffnet Esc das Menü. Am Gamepad schließt B, Start wirkt wie Esc. Die meisten Fenster nutzen UiFactory.Window (abgedunkelt, skaliert mit UiFitBox) mit Statuszeile und „SCHLIESSEN“ unten.

Ladebildschirm, Anmeldung, Fehler

LoadingScreen · LoadingScreen.cs
Vollbild-OverlayOrd 100automatisch, solange nicht im Spiel

Kein eigenes Login- oder Verbinden-Fenster: die Anmeldung läuft über das Ticket des Launchers, dieser Bildschirm zeigt alle Zustände.

Inhalt

  • Logo „BRIXEL“, Zeile „Bauen. Treffen. Spielen.“, Status, Detail, Fortschrittsbalken, „Version x Protokoll y“

Statuszeilen

  • Anmeldung wird geprüft · Verbinde mit dem Server · Welt wird geladen · Charakter wird erstellt · Instanz wird gewechselt · „Verbindung verloren – verbinde neu …“

Fehler

  • Titel: Konto gesperrt · Vom Server entfernt · Wartung · Verbindung fehlgeschlagen · Anmeldung nicht möglich
  • Details aus GameClient.Fail, z. B. „Bitte starte Brixel über den Launcher.“, „Die Spielinhalte brauchen eine neuere Version …“, „Alle Hubs sind gerade voll …“, „Der Server … ist nicht erreichbar.“
  • Knöpfe: ERNEUT VERSUCHEN (nicht bei Ticket-, Sitzungs-, Versions- oder Sperr-Fehlern), BEENDEN

Hinweise zu Sanktionen, Wartung, Support

kein eigenes Fenster
Toast / Chat-Systemzeile
  • Sanktionen (Core/Social/Sanctions.cs): „Du bist stummgeschaltet (…)“, „Dein Konto ist (dauerhaft) gesperrt …“, „Du wurdest vom Server entfernt.“ – als Toast, Chat-Systemzeile oder Fehlertitel im Ladebildschirm
  • Wartungs-Kick: Ladebildschirm mit Titel „Wartung“
  • Support-Antwort: Toast und Systemzeile „Der Support hat auf dein Ticket … geantwortet. Esc → Hilfe und Support.“
